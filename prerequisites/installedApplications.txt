PDFrenderServer prerequisite applications
========================================

Required Ubuntu packages:

- python3
  - Runs the PDFrenderServer HTTPS application using the Python standard library.
  - Detected version during setup: 3.12.3-0ubuntu2.1

- poppler-utils
  - Provides pdfinfo and pdftoppm for PDF metadata inspection and page rendering.
  - Detected version during setup: 24.02.0-1ubuntu9.9

- openssl
  - Generates and serves a self-signed TLS certificate for local HTTPS.
  - Detected version during setup: 3.0.13-0ubuntu3.11

Install command:

    sudo apt-get install -y python3 poppler-utils openssl
